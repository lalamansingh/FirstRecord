# Organization logo (optional)

FirstRecord ships with **no logo, emblem or insignia**. The sign-in page shows a neutral "FR" tile unless a logo file is placed here:

- `public/brand/logo.svg` (preferred) or `public/brand/logo.png` — square, transparent background, at least 256×256 px.
- Optionally set `NEXT_PUBLIC_ORG_NAME` in `.env.local` to use as the logo's alt text.

**Only place a logo here if you are authorized to use it.** Official emblems and insignia — including any design containing the State Emblem of India, police badges or department seals — are legally restricted (e.g. the State Emblem of India (Prohibition of Improper Use) Act, 2005). Use them only with written authorization from the owning department, and never on a prototype or demo deployment.

Logo files in this folder are not committed by default.
